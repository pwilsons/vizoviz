What is a PWA?

A PWA (progressive web app) is a website that can be added to the home screen of a phone. It gets its own icon and opens full screen without an address bar, like a normal app. It loads quickly on repeat visits, and the main pages can even open with a poor connection. Nothing needs to be installed from an app store.
